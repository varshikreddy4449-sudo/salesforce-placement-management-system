# Smart Placement Management System using Salesforce CRM

## Overview
A CRM-based Placement Management System built using Salesforce to automate recruitment workflows, student application tracking, and analytics.

## Features
- Student, Company, and Application Management
- Salesforce Flow Automation
- Smart Company Recommendation System
- Validation Rules for Application Limits
- Interactive Reports & Dashboards
- Recruitment Workflow Automation
- KPI Analytics & Hiring Trends

## Technologies Used
- Salesforce CRM
- Flow Builder
- Reports
- Dashboards
- Validation Rules
- Automation

## Key Functionalities

### Smart Recommendation Logic
Students receive recommended companies based on their skills:
- Salesforce → Salesforce company recommendation
- Python → Infosys recommendation
- Java → TCS recommendation
- Data Analytics → Accenture recommendation

### Validation Rules
Students cannot apply to more than 5 companies.

### Dashboards
- Students Applied Report
- Application Status Analytics
- Recommended Company Analytics
- Top Hiring Companies
